— Privacy First

Zero access to your data.

The HIMER agent runs in a fully isolated sandbox. It only processes anonymized compute packages.

What HIMER does NOT do

  • No access to personal files
  • No passwords or cookies
  • No browsing history
  • No data sold or transmitted
  • Only signed containers run
  • No webcam or microphone

What HIMER does

  • Processes anonymized math packages
  • Runs in WebAssembly sandbox
  • Reports only CPU, RAM, GFLOPS
  • Uses anonymous HIMER ID
  • Open-source auditable code
  • One-click instant stop
— Technical Documentation

How HIMER works from the inside.

1. Proof-of-Compute

Each node reports heartbeat. For each task, the node returns result + cryptographic hash. 5% are re-verified on witness nodes.

2. Earnings Formula

Transparent calculation per second of active contribution.

GFLOP-seconds= GFLOPS × (load / 100)
Gross= GFLOP-sec × $0.0001 × boost
Your share= Gross × user_share

3. Withdraw

Minimum withdraw $500. Fee 2%. Payment via Stripe Connect with identity verification. Available only after platform receives payments from clients.

— Privacy Policy

Privacy by Design.

Isolation Architecture

  • → Sandbox WASM/Docker: Code in isolated environment.
  • → Network whitelist: Only HIMER servers contacted.
  • → Open-source: Code on GitHub for audit.
